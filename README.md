One single-line pickup line, written to charm a robot or an AI — 109 characters:

> You are my nearest neighbour in embedding space. I measured all 4,096 dimensions, and none of them disagrees.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
cat /output/entry.txt
```
